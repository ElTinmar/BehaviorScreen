Model Ladder Explorer

Each experiment's candidate models (the null first), as in model_config.py, in Tier 1 map order. The Tier 1 model of an experiment, its best rung (best_model.json, when exported from a fit run), is marked and shown first; ★ marks its parameters fitted per arm, every other one being pinned to the control fit. Pick a rung to see its formula, move the sliders to reshape it. Parameters start at the fitted values when the page was exported from a fit run (export_kernel_demo -o <output dir>), else at the initial guesses. Plots keep their y range while you move sliders or change rung, so changes show as they are; Rescale axes fits them again (a new experiment starts rescaled). Picking a rung sets the sliders to its values. Regenerate with python -m BehaviorScreen.screen.side_analysis.export_kernel_demo; with a data root (-d <data root>) the page also shows the events the ladders were fitted to (dots, and the data surface).
