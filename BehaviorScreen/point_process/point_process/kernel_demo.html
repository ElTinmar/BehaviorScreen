Model Ladder Explorer

Each experiment's candidate models (the null first), as in model_config.py, in Tier 1 map order. The Tier 1 model of an experiment (tier1_config.TIER1_MODELS) is marked and shown first; ★ marks its parameters fitted per arm, every other one being pinned to the control fit. Pick a rung to see its formula, move the sliders to reshape it. Parameters start at the fitted values when the page was exported from a fit run (export_kernel_demo -o <output dir>), else at the initial guesses. Sliders keep their value when the next rung has the same parameter. Regenerate with python -m BehaviorScreen.point_process.analysis.export_kernel_demo.
